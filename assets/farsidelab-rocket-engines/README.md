# FarsideLab Rocket Engines — local asset snapshot

Downloaded on 2026-10-30 from <https://farsidelab.com/concept/rocket-engines/>.

## Contents

- `models/*.glb` — 13 rocket engine models, glTF 2.0, 1.3–4.2 MB each, 42 MB total.
- `manifests/*.json` — per-engine part metadata, explode offsets/order, spin axes, flow data.
- `catalog.json` — catalog copy: engine descriptions, reference engines, photos and photo credits.

All GLBs were checked for a valid `glTF` header, version 2, and matching declared length.
They use no Draco compression and contain no embedded animations.
